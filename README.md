# WDD 430 Portfolio

A simple portfolio application created with Next.js, TypeScript, Tailwind CSS, and the App Router for the WDD 430 course.

## Live Application

https://wdd430-portfolio-tawny.vercel.app

## GitHub Repository

https://github.com/canalesmejiad/wdd430-portfolio

## Features

- Home page displaying portfolio projects
- About page with a custom skills component
- Reusable Server Components
- Responsive design with Tailwind CSS
- API route at `/api/hello`

## Custom Component

`SkillCard.tsx` displays a reusable list of technical skills received through TypeScript props.
